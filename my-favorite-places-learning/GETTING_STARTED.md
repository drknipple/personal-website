# Getting Started with My Favorite Places Learning Project

Welcome! This is a step-by-step guide to help you learn web development by building a map-based application.

## Prerequisites

Before starting, you should have:
- Basic HTML/CSS knowledge
- Some JavaScript experience (variables, functions, basic concepts)
- A computer with internet access (Windows, Mac, or Linux)
- A web browser (Chrome, Firefox, Edge, or Safari)
- **Note**: We'll install VS Code in Week 1, and Node.js/npm/Git in Week 2!

## Installation Timeline

- **Week 1**: Install VS Code (code editor) - you'll use it right away!
- **Week 2**: Install Node.js, npm, and Git (needed for React projects)
- **Week 8**: Set up GitHub account (for deployment)

This way you get comfortable with VS Code from the start, and only install other tools when you need them!

**For Windows Users:**
- Week 2 includes detailed Windows installation instructions for all required tools
- Everything will be installed step-by-step with screenshots and troubleshooting tips

## How to Use This Project

1. **Start with Week 1** - Don't skip ahead! Each week builds on the previous.
2. **Read the README** - Each week has a detailed README explaining concepts.
3. **Try the Starter Code** - Start with the provided starter files.
4. **Check Examples** - If you get stuck, look at the example solutions.
5. **Practice** - Do the exercises to reinforce learning.

## Project Structure

```
my-favorite-places-learning/
├── week-01/          # HTML/CSS/JavaScript basics
├── week-02/          # Modern JS & React setup
├── week-03/          # React components & state
├── week-04/          # Forms & user input
├── week-05/          # Maps integration
├── week-06/          # Data storage & geocoding
├── week-07/          # Advanced features
└── week-08/          # Polish & deployment
```

Each week folder contains:
- `README.md` - Learning guide
- `starter/` - Code to start with
- `examples/` - Complete solutions
- `exercises/` - Practice problems

## Time Commitment

- **2-3 hours per day**
- **5 days per week**
- **8 weeks total**
- **Total: ~80-120 hours**

## Learning Approach

1. **Read** the week's README to understand concepts
2. **Code** along with the starter files
3. **Practice** with the exercises
4. **Review** examples if needed
5. **Build** your own version

## Getting Help

- Check the example solutions
- Read the linked resources
- Use browser DevTools to debug
- Ask questions (to your teacher/parent/mentor)

## Final Goal

By the end of 8 weeks, you'll have:
- A working map-based web app
- Knowledge of React, maps, and modern web development
- A project you can share with others
- Skills to build more apps!
