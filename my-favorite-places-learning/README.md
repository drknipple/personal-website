# My Favorite Places - Learning Project

This is a step-by-step learning project for building a map-based web application. Follow the week-by-week guides to learn React, maps, and modern web development!

## Project Structure

- `week-01/` - HTML/CSS Review & JavaScript Fundamentals
- `week-02/` - Modern JavaScript & Development Setup
- `week-03/` - React Basics - Components & State
- `week-04/` - Forms & User Input
- `week-05/` - Maps Integration
- `week-06/` - Data Persistence & Geocoding
- `week-07/` - Advanced Features
- `week-08/` - Polish & Deployment

## Getting Started

Start with Week 1! Each week builds on the previous one, so don't skip ahead.

Each week folder contains:
- `README.md` - Learning guide for that week
- `starter/` - Starter code to begin with
- `examples/` - Example solutions (look at these if you get stuck!)
- `exercises/` - Practice exercises

## Learning Approach

1. Read the week's README
2. Work through the starter code
3. Try the exercises
4. Check examples if you need help
5. Celebrate your progress! 🎉

## Final Goal

By the end of 8 weeks, you'll have built a fully functional app that:
- Shows locations on an interactive map
- Lets users add, edit, and delete locations
- Saves data in the browser
- Works great on phones
- Is deployed online for everyone to see!

Good luck and have fun learning! 🚀
